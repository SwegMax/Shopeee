# 🛍️ E-Commerce app with Flutter Search module

A modern Android e-commerce app built with native Android and Flutter modules.

## ✨ Features

- 🔐 **User Authentication**: Login & Register using Firebase
- 🛒 **Add to Cart** functionality
- 🧾 **Product Detail Page** with:
  - Selectable **product variations** (size, color, etc.)
  - Adjustable **quantity selector**
- 🔍 Integrated **FlutterSearch** module for fast and responsive product searching
- ☁️ Firebase as backend (Authentication, Database)

## 🧰 Tech Stack

- **Android** (Java/Kotlin)
- **XML ViewBinding**
- **Flutter Module** (for search functionality)
- **Firebase Authentication**
- **Firebase Realtime Database / Firestore**
- **Deployed to Google Play Store**

---

## 🚀 Getting Started

1. **Clone the repository**
   
2. **Open in Android Studio**

3. **Sync Gradle** and ensure the Flutter module loads correctly

4. **Add your** `google-services.json` **into the** `app/` **directory**

5. **Build and Run**
